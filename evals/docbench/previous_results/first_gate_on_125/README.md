# 开启验证门一轮：实验档案

本轮执行 L1 文档任务，开启语义验证门，视觉模型为 Qwen3-VL 30B。任务主模型与 DeepSeek 裁判均为 **DeepSeek Flash，未开启思考模式**。原选集 125 题，首跑后对 8 道链路失败题分两批补跑。

排除需要联网的 **`docbench:26:4`、`docbench:37:4`** 后，以共同 123 题统计，补跑合并成绩为 **DeepSeek Flash 96/123（78.05%）、Astra 104/123（84.55%）、Opus 5 105/123（85.37%）**。8 道失败题补跑后全部交付，合并结果仍保留 6 题回答后的进程异常退出。
