# 关闭验证门一轮：分析概要与评分分歧

本轮于 2026-09-14 运行：关闭语义验证门，视觉模型改为 Qwen3-VL 235B；任务主模型与 DeepSeek 裁判均为 DeepSeek Flash，未开启思考模式。排除需要联网的 `docbench:26:4`、`docbench:37:4` 后，共 123 题。

**本轮的主要进展是单次交付完整：123 题全部完成回答交付、后台收尾并正常退出。** 与开启验证门一轮的补跑合并成绩相比，三位裁判判对题数变化为 **+1、−1、+1**。验证门与视觉模型同时变化，这一结果反映的是整套配置的表现。

三列分别汇总模型裁判的评分。Astra 采用按 PDF 内容校准的 103 分，其中包含两道参考答案纠错；详细理由见其报告。评审可以看到既有评分或其他评审意见，属于非盲评。

## 关键问题与评审分歧

- **工具 ID 错误明显增加。** 本轮 703 次带附件 ID 的工具调用中，105 次抄错，涉及 51 题；同 123 题的旧首跑为 674 次调用、0 次抄错。122 对可比较的首次 L1 请求具有相同的系统提示词和工具目录，28 题第一次带 ID 的调用就已出错。完整 ID 并非新增要求，模型后端或解码变化仍是待验证假设。
- **视觉错读和输出不完整都存在。** `17:8`、`190:2` 的错误已出现在视觉模型的观察结果中；`32:1` 的输出在 Figure 6 标题处结束。后者缺少完成原因记录，截断原因尚未确定。
- **全文统计与工具使用仍是薄弱点。** 现有工具能提供物理页数等信息，难点在于全文覆盖、统一计数口径以及稳定地使用工具。正式交付中也包含错答和读取失败说明。
- **验证门对拒答的作用还需单独验证。** `108:2`、`165:0`、`151:3` 在两轮间出现答案变化，但旧轨迹未显示验证反馈修正了这些题的候选。共同题集上，开启验证门一轮的 Unanswerable 成绩更高；单独的开关对照尚未完成。
- **两位评审有三道分歧。** Astra 与 Opus 5 在 120 题上一致；`66:3`、`80:5`、`144:3` 为 Astra 0、Opus 5 1。Astra 的六道争议题清单不含 `144:3`。Opus 5 报告中的 102–111 分是指定争议题改判后的敏感性范围。

另外两处统计差异已核对：`156:4` 实际为 **24 个逻辑 attempt、25 次模型响应**，其中含一次修复响应；Opus 5 对旧 Astra 两题调整后的 102 分属于另一种评分假设，本页仍使用旧归档的 104 分进行比较。
