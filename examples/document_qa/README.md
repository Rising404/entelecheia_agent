# 原创文档问答样例

`harbor_handbook.pdf` 是一份三页英文文本 PDF，内容为完全虚构的 Harbor Learning Room
手册。组织、安排和数字均为原创合成，不使用用户材料、DocBench 原题或其他评测数据。
它用于熟悉上传文件、查找证据、跨页综合和承认信息缺失的过程，**不是 benchmark，也不代表性能或正确率证明**。
它没有扫描页或图片，不能用于证明视觉工具或复杂表格解析能力。

## 离线生成

先完成仓库公开安装流程，使用当前 checkout 自己的 Python 环境。
生成器仅使用 Python 标准库和已有依赖 ReportLab，不启动 Agent、不读应用配置、不下载材料、
不发起模型或网络调用，也不依赖 Codex。

在仓库根目录运行，先把示例中的输出路径替换为真实的**仓库外绝对路径**；其父目录须已存在：

```bash
.venv/bin/python examples/document_qa/generate_sample.py \
  --output /absolute/path/outside/checkout/harbor_handbook.pdf
```

唯一必需参数是 `--output`，它指定一个精确的 `.pdf` 文件，而不是目录。
生成器拒绝相对路径、仓库内路径（包括父目录通过符号链接指回仓库的情况）、已有文件和符号链接目标；
不会覆盖文件或自动创建目录。重复生成时请选择另一个仓库外的空闲文件路径。

源文件使用内置 Helvetica 字体、固定元数据和 ReportLab 的确定性模式；在生成源与 ReportLab
版本相同的环境中，重复生成应得到相同的 PDF 字节。不承诺不同 ReportLab 版本间逐字节相同。
仓库只维护生成源与说明，**不提交生成的 PDF 二进制**。

## 在 GUI 中尝试

按 [快速开始](../../QUICKSTART.md) 启动应用，创建用于本次尝试的会话，然后上传仓库外生成的
`harbor_handbook.pdf`。如果界面要求绑定目录，使用只含本次样例材料的仓库外目录。
不要把本源码目录或本说明作为附件/检索目录：下方包含复核答案，折叠显示不等于对 Agent 隐藏。

可以逐次输入以下中文问题；不要求固定工具、固定调用次数或固定执行顺序。
英文 query 提示只是人工查找线索，可选用，不会自动注入系统提示词或强制生成双语 query。
希望独立观察每题时，可各建一个会话并重新上传同一 PDF；同一会话连续提问则可能利用前轮历史。
实际在 GUI 提问仍使用你配置的模型服务，可能产生网络请求和 API 费用；只有生成 PDF 的步骤完全离线。

| 场景 | 可直接输入的问题 | 可选英文 query 提示 | 预期证据范围 |
| --- | --- | --- | --- |
| 直接查找 | 周五借用的绘图板最晚几点归还，交到哪里？请标明证据页。 | `Friday drawing boards return deadline location` | 第 1 页的归还安排 |
| 跨页综合/计算 | 为周六这场工作坊一共需要准备多少张彩色卡片？请列出计算过程并标明证据页。 | `colored cards per participant spare cards confirmed roster facilitators` | 第 2 页的材料规则和第 3 页的人数 |
| 信息不存在 | 周六工作坊每位参与者需要支付多少报名费？请仅依据这份手册回答；找不到就说明。 | `Saturday workshop registration fee price cost` | 检查全文第 1–3 页；没有支持金额的证据 |

页码均指 PDF 的物理页码，与每页页脚的 `1 / 3`、`2 / 3`、`3 / 3` 一致。
没有自动评分器；请核对回复使用了哪些文档证据，不要把“有回复”直接等同于“答案正确”。

1. **直接查找：**周五最晚 **16:30**，归还到 **Maple Desk**。第 1 页正文说明表格适用于绘图板，
   表格的 Friday 行给出时间和地点。不要混用周一至周四的 16:00。
2. **跨页综合：**第 2 页规定每位参与者 2 张，整场额外准备 6 张，不给引导员发卡片；
   第 3 页明确只有一场、18 位参与者，另有 2 位不计入参与者人数的引导员。因此为
   **18 × 2 + 6 = 42 张**。这些分项事实在 PDF 中，但总数和算式没有直接写在 PDF 中。

## 检查样例本身

在仓库根目录可运行定向检查：

```bash
.venv/bin/python -m pytest -q tests/scripts/test_document_qa_example.py
```

它检查三页结构、确定性生成、拒绝覆盖和仓内输出，以及现行 native PDF reader 能否保留
上述证据及物理页码。它不加载检索模型、不调用问答 Provider，不能替代 GUI 真实问答验收。
